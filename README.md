## About me

I am the founder of **DLSC Software & Consulting GmbH** in Zurich, Switzerland. My focus has always been the same: the user interface layer of serious Java applications — first with Swing, and today with **JavaFX**.

Most of my work happens where the UI gets hard: scheduling and planning views, timelines, calendars, large tables, and dashboards that have to stay responsive with a lot of data behind them. Over the years that has meant projects in aviation, logistics, finance and industrial planning.

Alongside client work I maintain a fairly large set of open source JavaFX libraries, and I run **JFXCentral**, the community website for everything JavaFX.
